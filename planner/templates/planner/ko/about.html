소개

이 도구

Neko Optimizer는 냥코 대전쟁의 뽑기 계획 도구입니다. 원하는 캐릭터와 티켓·고양이 통조림 예산을 알려 주면 어디서, 언제, 어떤 순서로 뽑아야 자원이 가장 적게 드는지를 계산합니다.

모든 뽑기는 하나의 공통 XOR-shift 난수 시드로 돌아가므로, 시드를 알면 앞으로의 뽑기 흐름은 모두 정해져 있습니다. Neko Optimizer는 자체 엔진으로 그 흐름을 로컬에서 계산하고, 뽑기를 상태 그래프로 다루며, A*와 빔 탐색으로 위시리스트를 모으는 가장 싼 경로를 찾습니다.

만든 사람

Iliyan Gavrilov의 개인 프로젝트입니다 — 경로 탐색, 결정론적 난수, 그리고 Django 앱 전체를 처음부터 끝까지 만들어 보려는 핑계로 시작했습니다. 소스 코드는 GitHub ↗에 있습니다.

사용한 기술

  • 브라우저에서 돌아가는 엔진은 Rust를 WebAssembly로 컴파일한 것입니다 — 뽑기 계산, A*/빔 탐색, 232개 시드를 전부 훑는 시드 찾기, 냥코 도감 스크린샷 읽기를 모두 Web Worker에서 실행합니다.
  • 참조용 엔진(난수, 뽑기 엔진, 그래프 생성, 탐색)과 게임 데이터 처리는 Python 3.14.
  • 웹 앱, 계정, ORM, 폼, 템플릿은 Django 6.1. 페이지 쪽은 순수 JavaScript입니다.
  • 운영 환경은 Vercel의 PostgreSQL, 로컬은 SQLite이며, 게임 데이터는 JSON으로 저장소에 포함되어 있습니다.
  • 테스트와 린트는 pytest와 ruff로, GitHub Actions에서 CodeQL·보안 검사와 함께 실행합니다.

크레딧

역분석된 뽑기 메커니즘 — XOR-shift 난수와 뽑기 엔진 내부(레어 중복 재추첨, 바운스, 확정 뽑기, 열 전환) — 은 godfat의 냥코 대전쟁 시드 트래커 ↗ (Apache-2.0)에서 왔습니다. Neko Optimizer는 이를 Python으로 옮기고, 골든 테스트로 godfat의 출력과 바이트 단위까지 일치하는지 검증합니다. 그 위의 계획 기능은 직접 만든 것입니다.

캐릭터 데이터와 아이콘은 battlecatsinfo ↗, 티어 순위는 battlecatstierlist.com ↗에서 가져왔습니다. Neko Optimizer는 팬이 만든 도구이며 PONOS와 관련이 없습니다.
