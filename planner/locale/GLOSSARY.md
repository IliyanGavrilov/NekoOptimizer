# Translation glossary

The terms every translation of the site uses, so a word means the same thing on every
page. Game terms are taken from the game's own text for that version wherever it has
one; the seed-tracker terms the game never uses come from each community's own guides.

Sources:

- **G** - the game itself: `resLocal/localizable.tsv` from the BCData tarballs, and the
  committed `neko/data/<region>/` item, talent, unit and banner names.
- **F** - godfat's Battle Cats Rolls, the proofread `data/{jp,tw}/l10n.yaml`.
- **C** - community guides: JP osamun-games.com / zatsures.com / Yahoo!知恵袋 table
  guides; TW Bahamut 貓咪大戰爭 board and 種子碼 tutorials; KR namu.wiki 뽑기 and the
  dcinside 냥코 배열 gallery.

Notes:

- "(English)" marks a name no source confirms for that version; it stays English rather than guessed.
- Cat, item and banner names are never translated here: every version's own data
  already carries them.
- tw/kr "step-up" has no settled community word; the descriptive form is used.
- The kr seed-tracker terms (배열, A열/B열, 레어 중복) come from one community (the
  dcinside 냥코 배열 gallery) and are the least corroborated row group; a native
  player's review matters most there.
